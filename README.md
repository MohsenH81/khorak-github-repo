# دفترچه خوراک من
1. همهٔ محتوای این پوشه را در ریپوی گیت‌هاب آپلود کن (شاخهٔ main).
2. Settings ← Pages ← Source: GitHub Actions (برای لینک نصب PWA).
3. تب Actions ← «Build APK» تمام شد ← پایین صفحه، Artifacts ← dafterche-khorak-apk (زیپ؛ داخلش فایل APK است).
4. APK را روی گوشی نصب کن (اجازهٔ نصب از منبع ناشناس لازم است).
